# CoSolve Lens 案例经验

本页记录八个去标识化课堂案例的评价摘要。公开材料不包含原始对话、会话标识、学生身份、来源成绩、提交文件、模型响应 ID 或 API Key；这些摘要只用于说明系统如何把过程证据转化为教学反馈。

五维顺序为：问题理解、信息甄别、分析推理、结果评价、策略调整。只有至少三维有充分证据时才计算过程均分。

## 为什么多数分数接近 2 分

量规不会为了形成漂亮分布而人为拉分。多个案例都呈现相同证据模式：学生能够提出疑问或报告错误，但缺少自己的取舍依据、对照结果或修正后验证，因此仍符合 2 分锚点。达到 3 分的维度通常同时具备明确目标、独立推理和可检查的策略选择。

## 如何把建议写成可执行动作

报告中的学生建议使用陈述式动作，而不是把责任重新变成问题。例如：

- 先写出预期结果，再运行最小示例并记录差异。
- 列出采用或跳过 AI 建议的理由和证据。
- 修正后重复同一测试，并保存可定位的运行结果。

每份建议还应附 1–2 个迁移练习和明确完成标准。
